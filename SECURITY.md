# Security Policy

## Supported versions

Tavo.js UI does not currently maintain a multi-version security support
policy. Only the latest npm release and the current `main` branch are
considered for security updates. Older releases may not receive fixes unless a
different support window is announced.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately
to [support@tavojs.dev](mailto:support@tavojs.dev).

Include the affected package and version or commit, reproduction steps, the
expected and actual behavior, security impact, affected configurations, and
any known workaround. Please also provide a safe way for the maintainers to
follow up if clarification is needed.

Do not access other people's data, disrupt services, degrade availability, or
perform testing beyond what is necessary to demonstrate the issue. Remove
secrets, credentials, and unrelated personal data from reports and
reproductions.

Please coordinate public disclosure with the maintainers so users have a
reasonable opportunity to update. The project does not promise a fixed
response or remediation time.
